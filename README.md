# YouTube Transcript Downloader: Text, SRT & VTT, No API Key

Fetch timestamped YouTube transcripts and captions as clean JSON without any API key or Google login. Supports any URL form: watch links, youtu.be, Shorts, and bare video IDs. Returns segments with start time and duration, a fullText string for RAG ingestion, and character count. Works as an MCP server in Claude, ChatGPT and any AI agent.

**Run it on Apify:** [apify.com/themineworks/youtube-transcript-scraper](https://apify.com/themineworks/youtube-transcript-scraper)
**Docs, FAQ and pricing:** [themineworks.com/actors/youtube-transcript-scraper](https://themineworks.com/actors/youtube-transcript-scraper/)

**Price:** $2.50 per 1,000 transcripts on Apify's free plan, down to $1.50 on higher plans. Failed and empty results are never charged.

* No API key or login required

## Input

| Field | Type | Default | Description |
|---|---|---|---|
| `videoUrls` | array |  | One or more YouTube videos, one per line |
| `outputFormats` | array | `["text", "segments"]` | Which transcript formats to return on each row |
| `language` | string | `"en"` | Language code of the caption track to prefer, for example en, es, hi, fr or pt |
| `includeTimestamps` | boolean | `true` | When on, rows include the segments array (start time and duration of each line, in seconds) if segments is… |

## Output

One row per result, as JSON, CSV, Excel or through the API.

| Field | Type | Description |
|---|---|---|
| `videoId` | string | The 11-character YouTube video ID |
| `url` | string | Canonical watch URL for the video (or the raw input when no video ID could be found) |
| `title` | string | Video title, when YouTube returned it |
| `language` | string | Language code of the caption track that was used |
| `isAutoGenerated` | boolean | True if the caption track is auto-generated by YouTube, false if it was uploaded or written by a person |
| `segmentCount` | integer | Number of transcript lines |
| `charCount` | integer | Character length of the full transcript text |
| `fullText` | string | The whole transcript as one readable string (output format: text) |
| `segments` | array | Ordered transcript lines, each { start, dur, text } in seconds (output format: segments, with… |
| `srt` | string | The transcript as an SRT subtitle file (output format: srt) |
| `vtt` | string | The transcript as a WebVTT subtitle file (output format: vtt) |
| `status` | string | ok (transcript returned, charged), no-caption-track or error (not charged), stopped or summary (run… |
| `reason` | string | Why a row is not ok, for example no-tracks-listed, video-unavailable, invalid-video-id, bot-check or… |

## FAQ

### How does it get transcripts without the YouTube API?

YouTube embeds caption track metadata in the watch page HTML inside the ytInitialPlayerResponse object. The actor extracts the timedtext endpoint URL from that response and fetches the caption XML directly. No API key or quota needed.

### What happens if a video has no captions?

The actor returns status "no-captions" for that video. You are not charged for videos without captions, only for transcripts actually delivered.

### Does it work with auto-generated (ASR) captions?

Yes. When no manual transcript is available it falls back to the auto-generated track. The isAutoGenerated field in the output tells you which was used.

### What language is returned?

The actor picks the track that best matches your preferred language. It tries an exact match first, then a language-prefix match (for example "en" matches "en-US"), then the video's default audio language, then the first available track.

### How much does the YouTube Transcript Downloader cost?

### Can I export the results to CSV or Excel?
